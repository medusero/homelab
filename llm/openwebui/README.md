# Open WebUI

[Open WebUI](https://github.com/open-webui/open-webui) es una interfaz web autoalojada para interactuar con modelos de lenguaje, con soporte nativo para Ollama y APIs compatibles con OpenAI.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Open WebUI, garantizando que la aplicación esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
