# Radarr

[Radarr](https://github.com/Radarr/Radarr) es un gestor de colecciones de películas que monitoriza y busca automáticamente nuevos lanzamientos, integrándose con clientes de descarga Usenet/BitTorrent para gestionar y mantener actualizada tu biblioteca de cine.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Radarr, garantizando que la interfaz de gestión esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
