# Linkwarden

[Linkwarden](https://github.com/linkwarden/linkwarden) es un gestor de marcadores autoalojado y de código abierto que permite guardar, organizar y archivar enlaces de forma colaborativa, con capturas de pantalla y copias en PDF automáticas para preservar el contenido aunque desaparezca de internet.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Linkwarden, garantizando que tu colección de enlaces esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
