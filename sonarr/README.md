# Sonarr

[Sonarr](https://github.com/Sonarr/Sonarr) es un gestor de colecciones de series de televisión que monitoriza, busca y descarga automáticamente nuevos episodios, integrándose con clientes de descarga Usenet/BitTorrent para mantener tu biblioteca de series al día.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Sonarr, garantizando que la interfaz de gestión esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
