# Copyparty

[Copyparty](https://github.com/9001/copyparty) es un servidor de ficheros portátil con subidas reanudables aceleradas, deduplicación y soporte para WebDAV, SFTP, FTP, TFTP, zeroconf, indexador multimedia y generación de miniaturas, todo contenido en un único fichero sin dependencias externas.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Copyparty, garantizando que el acceso a tus ficheros esté protegido frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
