# Lidarr

[Lidarr](https://github.com/Lidarr/Lidarr) es un gestor de colecciones de música que monitoriza tu biblioteca y se integra con clientes de descarga Usenet/BitTorrent para buscar y descargar automáticamente los álbumes que faltan.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Lidarr, garantizando que la interfaz de gestión esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
