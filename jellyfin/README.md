# Jellyfin

[Jellyfin](https://github.com/jellyfin/jellyfin) es un sistema multimedia de software libre que te permite gestionar y transmitir tu colección de películas, series, música y fotos, sin coste y sin seguimiento de datos por parte de terceros.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Jellyfin, garantizando que tu servidor multimedia esté protegido frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
