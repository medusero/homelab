# Papra

[Papra](https://github.com/papra-hq/papra) es una aplicación de gestión documental autoalojada, pensada para organizar, archivar y buscar tus documentos, con OCR, etiquetado automático y funciones de IA opcionales.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Papra, garantizando que la aplicación esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
