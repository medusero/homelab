# Immich

[Immich](https://github.com/immich-app/immich) es una solución de código abierto y autoalojada para la copia de seguridad y gestión de fotos y vídeos, pensada como alternativa a Google Fotos, con subida automática desde el móvil, reconocimiento facial, búsqueda inteligente y organización mediante inteligencia artificial.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Immich, garantizando que tu biblioteca de fotos y vídeos esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
