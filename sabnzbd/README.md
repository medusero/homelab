# SABnzbd

[SABnzbd](https://github.com/sabnzbd/sabnzbd) es un descargador de binarios Usenet de código abierto que automatiza la descarga de ficheros desde grupos de noticias, con reparación, extracción y verificación automáticas.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de SABnzbd, garantizando que la interfaz de gestión esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
