# Paperless-ngx

[Paperless-ngx](https://github.com/paperless-ngx/paperless-ngx) es un sistema de gestión documental de código abierto que escanea, indexa y archiva tus documentos en papel, convirtiéndolos en un archivo digital consultable mediante reconocimiento óptico de caracteres (OCR) y etiquetado automático.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Paperless-ngx, garantizando que tus documentos estén protegidos frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
