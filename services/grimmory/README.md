# Grimmory

[Grimmory](https://github.com/grimmory-tools/grimmory) es una biblioteca digital autoalojada para quienes se toman en serio la lectura, un fork comunitario independiente de Booklore. Ofrece estanterías inteligentes con filtrado por reglas, búsqueda y edición de metadatos, un lector integrado para PDF, EPUB y cómics con anotaciones y progreso de lectura, sincronización con dispositivos como Kobo y KOReader, y soporte multiusuario.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Grimmory, garantizando que tu biblioteca esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
