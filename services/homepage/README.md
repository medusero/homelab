# Homepage

[Homepage](https://github.com/gethomepage/homepage) es un panel de inicio moderno, completamente estático, rápido, seguro y altamente personalizable para tus aplicaciones autoalojadas, con integraciones para mostrar el estado de tus servicios, widgets y marcadores en un único lugar.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Homepage, garantizando que el panel esté protegido frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
