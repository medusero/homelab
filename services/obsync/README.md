# Obsync (CouchDB para obsidian-livesync)

Backend [CouchDB](https://couchdb.apache.org/) para el plugin de Obsidian [`obsidian-livesync`](https://github.com/vrtmrz/obsidian-livesync), usado para sincronizar bóvedas de Obsidian entre dispositivos.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de CouchDB, garantizando que tus archivos de notas estén protegidos frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
