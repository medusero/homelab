# Shelfmark

[Shelfmark](https://github.com/calibrain/shelfmark) es una interfaz web autoalojada para buscar y solicitar libros y audiolibros de múltiples fuentes, permitiendo combinar tus propias fuentes, proveedores de metadatos y clientes de descarga en un único punto centralizado, con soporte multiusuario y sistema de solicitudes integrado.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Shelfmark, garantizando que la interfaz esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
