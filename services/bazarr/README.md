# Bazarr

[Bazarr](https://github.com/morpheus65535/bazarr) es una aplicación de código abierto autoalojada para gestionar y descargar subtítulos de tus películas y series. Funciona junto con otros gestores multimedia como Sonarr y Radarr para buscar y descargar automáticamente subtítulos de diversas fuentes.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Bazarr, garantizando que la interfaz de gestión de subtítulos esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
