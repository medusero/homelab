# Karakeep

[Karakeep](https://github.com/karakeep-app/karakeep) (antes conocida como Hoarder) es una aplicación para guardar todo tipo de marcadores que puedes alojar tú mismo y que incorpora un toque de inteligencia artificial, pensada para los que les gusta atesorar datos.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Karakeep, garantizando que la aplicación esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
