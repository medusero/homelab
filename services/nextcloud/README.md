# Nextcloud

[Nextcloud](https://nextcloud.com) ofrece una moderna plataforma de colaboración de contenidos in situ con edición de documentos en tiempo real, videochat y trabajo en grupo en el móvil, el escritorio y la web.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Nextcloud, garantizando que tus archivos están protegidos frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
