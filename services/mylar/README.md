# Mylar

[Mylar](https://github.com/MylarComics/mylar3) es un gestor automatizado de cómics para Usenet y BitTorrent que monitoriza y descarga automáticamente los números nuevos de tus series de cómics favoritas, con soporte para metadatos y organización de la colección.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Mylar, garantizando que la interfaz de gestión esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
