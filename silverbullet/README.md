# Silverbullet

[SilverBullet](https://github.com/silverbulletmd/silverbullet) es una base de datos de conocimiento personal programable, privada, basada en navegador, de código abierto y autohospedada; un término sofisticado para referirse a una «aplicación de notas potenciada al máximo».
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Baikal, garantizando que tus notas estén protegidas frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
