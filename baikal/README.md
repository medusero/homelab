# Baikal

[Baikal](https://github.com/sabre-io/Baikal) es un servidor CalDAV y CardDAV ligero y de código abierto que permite gestionar calendarios y libretas de contactos de forma centralizada, con una interfaz web sencilla para administrar usuarios, calendarios y libretas de direcciones. Es rápido y fácil de instalar, y solo necesita un servidor con PHP y una base de datos MySQL o SQLite.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Baikal, garantizando que la interfaz de gestión esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
