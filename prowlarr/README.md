# Prowlarr

[Prowlarr](https://github.com/Prowlarr/Prowlarr) es un gestor de indexadores que se integra con aplicaciones como Sonarr, Radarr y Lidarr, centralizando la configuración de indexadores de Usenet y BitTorrent para toda tu suite de gestores multimedia.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Prowlarr, garantizando que la interfaz de gestión esté protegida frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
