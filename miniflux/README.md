# Miniflux

[Miniflux](https://github.com/miniflux/v2) es un lector de fuentes RSS/Atom minimalista y de código abierto, centrado en la simplicidad, la velocidad y el bajo consumo de recursos.
Esta configuración utiliza Tailscale para conectarse de forma segura a tu instancia de Miniflux, garantizando que tu lector de noticias esté protegido frente a accesos no autorizados y que tu instancia solo sea accesible a través de tu red privada de Tailscale.
